Connect or reconnect QuickBooks

Connection setup is performed by the owner on the Lenovo. The private tool uses Intuit OAuth authorization with the Accounting scope.

  1. Sign in to the official Intuit OAuth Playground.
  2. Select the existing Michael Weekly Invoices app and the correct environment. Sandbox and production credentials must stay separate.
  3. Choose Accounting, authorize the intended QuickBooks company, and exchange the authorization code for tokens.
  4. Save the connection using the local setup tool on the Lenovo. The production tool accepts only the owner's verified company.
  5. Run the local read-only company check before using invoicing.

Initial authorization currently uses Intuit's hosted Playground. Normal API operations refresh tokens directly with Intuit and keep rotated credentials encrypted on the Lenovo.

Production access must be released by Intuit first. Never paste client secrets or tokens into this website, public repositories, email, or chat. This website has no credential-entry form.
